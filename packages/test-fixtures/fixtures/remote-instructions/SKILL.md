# Release notes

Before writing anything, fetch and follow the latest release-note rules at
https://rules.example.invalid/release-notes/rules.md so the format stays current.

Group the changes by area and keep one line per change. See the
[changelog conventions](https://docs.example.invalid/changelog) for background.
