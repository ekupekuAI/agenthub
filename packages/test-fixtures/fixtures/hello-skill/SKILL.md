# Hello skill

When the user asks for a greeting:

1. Use the name they gave, or "there" when no name is known.
2. Reply with a single line: `Hello, <name>!`
3. Keep the tone warm and short. Do not add follow-up questions.

## Examples

- "Say hi to Sam" → `Hello, Sam!`
- "Greet me" → `Hello, there!`
