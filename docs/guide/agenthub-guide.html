✓agenthub · quick guide

Install agent skills you can trust.

One command installs a skill into Claude Code, Codex, Cursor and VS Code. agenthub scans it first, checks it against what it declares, and records every byte, so you can verify, update and roll back.

Install (Node.js 22+)
npm install -g @ekupekuai/agenthub
then type agenthub in any terminal

01What it is

AI coding tools learn skills: folders with a SKILL.md plus optional scripts (the open Agent Skills format). agenthub is the package manager and trust layer for them: one place to find, check, install, update and undo skills across all your agents.

Claude Codereads .claude/skills Codexreads .agents/skills Cursor, VS Coderead both

agenthub writes the smallest set of folders that covers every agent you use.

02First five minutes

# 1. check your machine and agents
agenthub doctor
# 2. find a skill
agenthub search testing
agenthub info web-testing
# 3. install it (run inside your project)
agenthub install web-testing
# 4. confirm nothing changed
agenthub verify

Every install shows a plan first: folders, agents, findings and requirements. Nothing is written until you confirm.

04Everyday commands

install <skill>install from the registry (name@^1.2 works)
install ./folderinstall a local skill or .skillpkg
installrestore everything in the lockfile
listinstalled skills, agents, approval
verifyre-hash files, report edits (exit 4)
update --checkavailable updates, changes nothing
update --safeapply only updates that add nothing new
diff <skill>what the next version can do extra
approve <skill>record approval of its capabilities
rollback <skill>restore the previous version
remove <skill>remove only files agenthub installed
pack ./folderbuild a reproducible .skillpkg

Flags: --dry-run plan only · --yes no prompt · -g all projects · --agent claude-code,cursor · --json for scripts & CI

05How safety works

Before anything is written, a static scanner checks every file and compares what it finds with what the skill declares in agenthub.yaml.

INFObehavior the skill declared, shown to you
WARNundeclared network, programs or env reads: you must confirm
BLOCKsecret reads, download-and-run, obfuscation, hidden instructions, persistence: install stops

agenthub never runs a skill's scripts. Installs are all-or-nothing, and a failed update restores the old version.

06Updates you approve

Each version gets a capability inventory: programs it runs, hosts it contacts, env vars and secrets it reads, external links it follows. If an update can do more than the version you approved, agenthub stops:

+ network  telemetry.example.com
+ exec     uvx
This update can do more than the
version you approved.  Approve? [y/N]

--yes alone never approves new capabilities; use --approve-capabilities after agenthub diff.

07Teams & projects

Inside a git project, skills install into that project and are recorded in .agenthub/agenthub.lock (versions + per-file hashes). Commit the lockfile and the skill folders: teammates get identical skills on clone, and agenthub verify catches tampering.

08Publish your own skill

# agenthub.yaml next to SKILL.md
schema: 1
version: 1.0.0
permissions:
  network: [registry.npmjs.org]
  exec: [npx, node]

Check with agenthub install ./my-skill --dry-run, then agenthub pack ./my-skill and upload it on the website's Publish page. Versions are immutable; every upload is scanned.
